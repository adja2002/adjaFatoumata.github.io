# Portfolio — Adja Fatoumata Ndao

Site statique (HTML/CSS) prêt pour GitHub Pages.

## Mise en ligne
1. Crée un dépôt nommé `adja2002.github.io` sur GitHub.
2. Dépose-y le contenu de ce dossier (`index.html`, `img/`, `cv-adja-ndao.pdf`).
3. Settings → Pages → Source : branche `main`, dossier `/ (root)`.
4. Le site est en ligne sur https://adja2002.github.io quelques minutes après.
